rd Desktop now updates itself. It checks for a new version at launch and every few hours, downloads it in the background and, when you're not in a session, shows what's new since your version with a **Restart & update** button. A new tray (menu bar) icon, the macOS app menu and the Windows title-bar menu have **Check for Updates…**; automatic checks can be turned off in the tray menu. On macOS the app is now signed with a stable certificate, so the Accessibility permission survives updates (grant it once more after installing this version).
