File transfer: browse this machine's files from the viewer, download files and folders (as a zip), upload files and folders, create folders, rename, and move things to the Trash or Recycle Bin. Transfers resume after a dropped connection and back off so the screen stays smooth. On a Mac, macOS asks once per folder (Desktop, Documents, Downloads) unless RD Agent has Full Disk Access.
