## Made for networks that only speak HTTPS

A locked-down work laptop may block VNC, RDP, SSH and anything else that isn't a web browser on
port 80 or 443. rd works within those limits: both ends connect _out_ to a small gateway, and the
traffic looks like any other web app.

<Architecture />

## Current, not queued

Most streaming tools fill a buffer when the network slows down, and the picture falls further and
further behind. rd works the other way around: the viewer acknowledges every frame, and when the
link can't keep up the agent skips frames before encoding and lowers the bitrate. You may see
fewer frames for a moment, but what you see is current.

## Everything for daily use

<FeatureGrid>
	<Feature icon="browser" title="Runs in a browser tab">
		Any modern browser with WebCodecs. Nothing to install on the computer you sit at.
	</Feature>
	<Feature icon="outbound" title="Outbound only">
		The agent dials out to the gateway, so no ports are open on your home router.
	</Feature>
	<Feature icon="bolt" title="Low latency">
		Hardware H.264 at up to 60 or 120 fps, with a bitrate controller tuned in a network
		simulator.
	</Feature>
	<Feature icon="lock" title="Hands off the lock screen">
		While the host is locked, the agent drops all input, so nothing is ever typed into a
		password field by accident.
	</Feature>
	<Feature icon="keyboard" title="A keyboard that works">
		Physical key codes, Caps Lock sync and automatic Windows ⇄ Mac modifier mapping (Ctrl ⇄
		Cmd).
	</Feature>
	<Feature icon="command" title="System shortcuts, with rd Desktop">
		The desktop app also captures Alt+Tab, Cmd+Tab and the Windows key, which a browser tab
		normally never receives.
	</Feature>
	<Feature icon="displays" title="Multiple displays">
		Switch between the host's screens. Pointer lock, and scaling that keeps the aspect ratio.
	</Feature>
	<Feature icon="user" title="Single sign-on">
		Authentik in front of the portal, an email allowlist, and a separate token for every
		device.
	</Feature>
	<Feature icon="plus" title="Add device in the portal">
		The portal shows a setup code, once, to paste into the agent's setup. No restart.
	</Feature>
	<Feature icon="signal" title="Network probe">
		A built-in test checks whether a network can carry a session before you rely on it.
	</Feature>
	<Feature icon="refresh" title="Updates itself">
		Signed updates for rd Desktop and the agents. An agent rolls back if the new version
		doesn't come back.
	</Feature>
	<Feature icon="lifebuoy" title="Recovery path">
		Mac locked, logged out or rebooted? With a little setup at home, Apple Screen Sharing over
		Guacamole gets you back in.
	</Feature>
</FeatureGrid>
